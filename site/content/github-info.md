## Recent updates worth watching

- **Pull request Overview page (public preview):** Opt-in preview that puts merge status and next available actions at the top of long pull requests. [GitHub Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview)
- **Secret scanning for GitHub Actions logs (public preview):** Secrets in workflow run logs now surface as secret scanning alerts for supported GitHub Enterprise Cloud plans. [GitHub Changelog](https://github.blog/changelog/2026-11-09-secret-scanning-detects-secrets-in-github-actions-workflow-logs)
- **A more informative GitHub dashboard:** A more compact dashboard that shows six pull requests and issues by default, with a pinnable Feed or Home tab. [GitHub Changelog](https://github.blog/changelog/2026-11-10-a-more-informative-github-dashboard)
